# skills

My Claude skills. Each folder in [`skills/`](skills) is one skill: a `SKILL.md` with frontmatter (`name`, `description`) and any supporting files.

| Skill | What it does |
|---|---|
| [course-exam-study](skills/course-exam-study) | Turns a course's lecture slides, tutorials and solutions into styled notes + cheat sheet PDFs and/or exam-format practice tests (chapterwise mastery, full-syllabus, or study-then-test). |
| [resume-writer](skills/resume-writer) | Crafts a role-tailored resume in the Jake Ryan LaTeX template and compiles it to PDF. |

## Using a skill

- **claude.ai / Claude app:** zip the skill's folder and upload it under Settings → Capabilities → Skills.
- **Claude Code:** copy the folder into `~/.claude/skills/` (or `.claude/skills/` in a project).
